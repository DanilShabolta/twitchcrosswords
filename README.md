# 🧩 Twitch Interactive Crossword Extension

Интерактивное расширение для Twitch, с помощью которого зрители прямо в чате отгадывают слова в кроссворде.

## ✨ Основные возможности

- **👁️ Зрители сами решают, видеть ли им оверлей**: Плавающая кнопка **"Скрыть / Показать кроссворд"** позволяет каждому зрителю свернуть или развернуть интерфейс расширения на стриме в любой момент.
- **💬 Управление через Twitch Чат**: Зрители пишут ответы в формате: `1. свияжск`, `1 свияжск`, `!1 свияжск`, `#1 свияжск`.
- **⚙️ Автоматическая генерация кроссвордов**: Встроенный алгоритм строит сетку с пересечением слов и базой данных на русском языке.
- **🏆 Топ за раунд и за всё время**: Рекорды сохраняются в `data/leaderboard.json`, переключение между «Этот раунд» / «За всё время» в оверлее.
- **❌ Уведомление о неверных ответах**: При неправильном ответе бот уведомляет зрителя в чате и показывает красный тост на оверлее.
- **🌐 Загрузка кроссвордов с сайтов**: Поддержка загрузки готовых кроссвордов по URL или из тематических онлайн-наборов.
- **✨ Красивый Twitch-дизайн**: Тёмная тема с эффектами Glassmorphic, неоновыми подсветками и плавными анимациями.
- **🎛️ Панель управления Стримера**: Панель для перезапуска игр, переключения каналов и вывода подсказок.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка `.env`

Скопируй `.env.example` в `.env` и заполни свои данные:

```bash
copy .env.example .env
```

Основные параметры в `.env`:
```env
TWITCH_TOKEN=oauth:ВАШ_ТОКЕН_ЗДЕСЬ
TWITCH_CHANNEL=название_вашего_канала
BOT_USERNAME=CrosswordBot
```

Токен бота получи на [twitchapps.com/tmi](https://twitchapps.com/tmi) (войди под аккаунтом бота).

Или укажи канал и токен прямо в расширении через страницу `config.html` после запуска сервера.

### 3. Запуск сервера
```bash
npm start
```

После запуска доступно два URL:
- 🌐 **Оверлей для зрителей / Twitch Extension:** `http://localhost:3000`
- 🎛️ **Панель управления стримера:** `http://localhost:3000/dashboard.html`

## 🌐 Загрузка кроссвордов с веб-сайтов

В **Панели управления** (`/dashboard.html`) можно загружать кроссворды из интернета:
1. **Случайный по теме** — кнопка «Загрузить случайный кроссворд с сайта»
2. **По URL** — вставить ссылку на страницу с кроссвордом и нажать «Загрузить по URL»

### Поддерживаемые сайты (нормально парсятся)

| Сайт | Примечание |
|------|-----------|
| **graycell.ru/onlinecross/** | Полная поддержка. Встроенный специальный парсер с XOR-декодированием. Пример: `https://www.graycell.ru/onlinecross/cross445.html` |
| Встроенные тематические наборы | Всегда работают: Кино, Игры, География, Наука |

### Ограничения парсинга произвольных сайтов

Парсинг «по URL» с произвольных сайтов работает **только** если на странице есть текстовые пары «слово — описание» (например, списки вопросов и ответов в HTML).

**Не будут работать** сайты, которые:
- Отображают кроссворд только через JavaScript (SPA/React/Angular)
- Хранят данные в обфусцированном/нестандартном формате (каждый сайт уникален)
- Требуют авторизацию или антибот-защиту (Cloudflare и т.п.)

> **Совет**: Для наилучшего результата используйте `graycell.ru` или встроенные тематические наборы.

## 📺 Подключение к Twitch

### Вариант 1: Как Twitch Extension (Видео-оверлей / Панель)
1. В [Twitch Developer Console](https://dev.twitch.tv/console/extensions) создайте новое Extension.
2. В качестве URL оверлея укажите адрес вашего сервера (например `http://localhost:3000` при локальном тестировании).

### Вариант 2: Через OBS Browser Source (Браузерный источник)
1. В OBS добавьте источник **Браузер (Browser Source)**.
2. Введите URL: `http://localhost:3000`.
3. Установите ширину `1920` и высоту `1080`.

## 🎮 Как играть зрителям

1. На стриме появится кнопка **Скрыть / Показать кроссворд**. Зритель может кликнуть по ней, если хочет скрыть или открыть кроссворд снова.
2. Зрители читают вопросы в блоке вопросов или на сетке.
3. Зритель пишет в чат трансляции: `1. свияжск` или `2 арбуз`.
4. Бот моментально проверяет ответ:
   - **Верно** — открывает буквенные ячейки, начисляет очки и поздравляет зрителя!
   - **Неверно** — отправляет уведомление в чат и на оверлей.
